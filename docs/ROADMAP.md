# Roadmap - co nowego dla graczy

Lista planowanych funkcji i usprawnien z perspektywy uzytkownika.
Legenda: 🟢 latwe | 🟡 srednie | 🔴 trudne

---

## Interfejs i wygoda

- [ ] 🟢 Tryb ciemny / jasny do wyboru w ustawieniach
- [ ] 🟡 Motyw kolorystyczny do wyboru (np. retro, lesny, pustelniczy)
- [ ] 🟢 Zapamietywanie ukladow okien na profil (np. "walka", "eksploracja", "handel")
- [ ] 🟡 Szybkie przelaczanie miedzy profilami ukladu jednym przyciskiem
- [ ] 🟢 Powiadomienia dzwiekowe o waznych wydarzeniach (atak, wiadomosc, smierc)
- [ ] 🟡 Powiadomienia systemowe przegladarki (nawet gdy karta jest w tle)
- [ ] 🟢 Podglad statystyk postaci na stale widocznym pasku bocznym
- [ ] 🟡 Dostosowywanie rozmiaru i czcionki terminala

## Mapa i nawigacja

- [ ] 🟢 Ulubione lokacje z wlasnymi ikonkami i kolorami
- [ ] 🟡 Historia odwiedzonych pokoi z mozliwoscia filtrowania
- [ ] 🟡 Automatyczne oznaczanie miejsc z questami / NPC
- [ ] 🟢 Szybkie teleportowanie do ostatnich lokacji (lista "ostatnio odwiedzone")
- [ ] 🔴 Wspoldzielenie oznaczen na mapie z innymi graczami
- [ ] 🟡 Mini-mapa widoczna obok terminala bez otwierania osobnego okna
- [ ] 🟢 Eksport / import oznaczen i notatek na mapie

## Walka

- [ ] 🟡 Panel podsumowania walki - obrazenia zadane/otrzymane, czas trwania
- [ ] 🟢 Wizualny pasek zdrowia/many celu ataku (jesli dostepny)
- [ ] 🟡 Historia walk z mozliwoscia przegladania statystyk
- [ ] 🟢 Szablony zestawow walki (bron + tarcza + komendy) do szybkiego przelaczania
- [ ] 🟡 Timer odnowien umiejetnosci i mikstury

## Ekwipunek i handel

- [ ] 🟢 Szybki podglad zawartosci wszystkich pojemnikow w jednym widoku
- [ ] 🟡 Porownywanie przedmiotow obok siebie (statystyki)
- [ ] 🟢 Oznaczanie przedmiotow jako "nie sprzedawaj" / "do sprzedania"
- [ ] 🟡 Lista zakupow - co chce kupic i gdzie to dostane
- [ ] 🟢 Historia depozytu bankowego w formie wykresu

## Komunikacja

- [ ] 🟢 Oznaczanie rozmow jako wazne / do przeczytania pozniej
- [ ] 🟡 Wyszukiwanie w historii czatu po slowie kluczowym
- [ ] 🟢 Blokowanie wiadomosci od wybranych graczy
- [ ] 🟡 Szablon szybkich odpowiedzi (gotowe wiadomosci do wyslania jednym kliknieciem)
- [ ] 🟢 Powiadomienie o nowej wiadomosci prywatnej gdy jestes w walce

## Automatyzacja i skrypty

- [ ] 🟡 Gotowe paczki automatyzacji do pobrania (np. "rybak", "zielarz", "wojownik")
- [ ] 🟢 Wlacz/wylacz trigger jednym kliknieciem bez wchodzenia w ustawienia
- [ ] 🟡 Wizualny edytor triggerow (bez pisania regexow)
- [ ] 🟢 Grupy triggerow - wlaczanie/wylaczanie calego zestawu naraz
- [ ] 🟡 Udostepnianie wlasnych aliasow i triggerow innym graczom przez link

## Postepy i statystyki

- [ ] 🟡 Panel postepu postaci - wykresy rozwoju umiejetnosci w czasie
- [ ] 🟢 Dziennik przygod - automatyczny zapis waznych wydarzen (nowy poziom, quest, smierc)
- [ ] 🟡 Porownanie postepu z poprzednim tygodniem/miesiacem
- [ ] 🟢 Osiagniecia / odznaki za kamienie milowe (np. "1000 potworow", "wszystkie ziola")
- [ ] 🔴 Ranking graczy (jesli serwer udostepni dane)

## Mobilnosc

- [ ] 🟡 Lepsze dostosowanie interfejsu do malych ekranow
- [ ] 🟢 Gesty dotykowe do czestych akcji (swipe = kierunek, przytrzymanie = atak)
- [ ] 🟡 Tryb oszczedzania baterii (mniej animacji, rzadsze odswiezanie mapy)
- [ ] 🟢 Szybkie akcje z ekranu blokady (powiadomienia z przyciskami)

## Spolecznosc

- [ ] 🟡 Lista znajomych z podgladem kto jest online
- [ ] 🟢 Notatki o graczach (np. "kupiec w Tarnowie", "uzdrowiciel")
- [ ] 🟡 Wspolne listy zakupow / celow druzyny
- [ ] 🔴 Wbudowany poradnik dla nowych graczy z interaktywnymi wskazowkami

---

> Ten dokument opisuje kierunek rozwoju z perspektywy gracza.
> Kolejnosc i zakres moga sie zmieniac w zaleznosci od potrzeb spolecznosci.
